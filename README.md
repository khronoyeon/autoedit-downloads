# AutoEdit · 자동 편집

일반 사용자를 위한 설치 파일과 다운로드 안내만 보관하는 저장소입니다.
앱 소스 코드와 개인 영상·작업 파일은 포함하지 않습니다.

[다운로드 페이지](https://khronoyeon.github.io/autoedit-downloads/)

- Mac: Apple Silicon, macOS 14 이상
- Windows: Windows 10/11 x64, 설치 시 관리자 권한 필요
- 현재는 개발자 서명·Apple 공증이 없는 사전 체험판입니다.
- 검증된 설치 파일만 다운로드 페이지에서 활성화합니다.
- 외부 도구의 공개 소스·라이선스 자료는 같은 배포 버전의 첨부 파일로 제공합니다.

검사 작업의 기본 권한은 읽기 전용입니다.
